# contributing ♡

thanks for wanting to help with Strawberry Cloud!

## found a bug?
open an [issue](../../issues) with:
- your obsidian version + light or dark mode
- a screenshot of what looks wrong
- which plugins / snippets you have on

## want to change something?
1. fork the repo and edit `theme.css`
2. test it: copy `theme.css` + `manifest.json` into `.obsidian/themes/Strawberry Cloud/` in a test vault
3. keep it tidy: no `!important`, no `:has()`, no remote fonts or images
4. open a pull request with a before/after screenshot

## ideas
feature ideas are welcome as issues too. please keep things soft, cute and readable ♡
